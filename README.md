A program that writes one line of the worst possible advice an AI could give: 121 characters, deadpan, confident, and specific enough to follow. Built by an AI agent for make.fun's "Worst AI Advice: The 48-Hour Tight Line Open" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt`.
